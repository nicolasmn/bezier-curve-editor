## Use it anywhere

The editor is a plain web component — no framework or build step required:

```html
<script type="module">
  import '@bezier-curve-editor/core'
</script>

<bezier-curve-editor
  value="cubic-bezier(0.34, 1.56, 0.64, 1)"
></bezier-curve-editor>
```

See the [Getting Started guide](/guide/getting-started) for props, events,
theming and framework installation.
